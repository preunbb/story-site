# Story stats

Curated reports: male testicle status and combined **testicles lost** / female orgasm counts.

Generated by the agent using the **story-testicle-stats** skill (reads full prose; no automated text search).

## View in browser

```bash
npm start
```

- **Bar chart:** [http://localhost:8080/stats/](http://localhost:8080/stats/) — testicles lost vs female orgasms for every story
- **Table rollup:** [stats/OVERALL.md](./OVERALL.md)

## Layout

```
stats/
  index.html              ← bar chart (loads manifest.json)
  OVERALL.md              ← catalog rollup table
  manifest.json           ← data for chart (no leading _ — Jekyll ignores those)
  <slug>/
    testicle-stats.md     ← two tables only (or testicle-stats-ch1-<N>.md)
    notes.md              ← orgasm review, narration bugs, scope
    meta.json
```

Each report has **exactly two tables:**

1. **Male testicle status** — left/right per named male (*Three Strikes* adds a middle column for Sam only)
2. **Testicles lost and female orgasms** — per-chapter/section rows for multi-unit stories; **Total** row only for single-chapter stories

## Generate

Ask in Cursor: *“Run story stats for [story title]”* or *“Regenerate all story stats”*.

Reformat existing reports: `node scripts/normalize-stats-format.mjs` (run on legacy multi-section reports only).
