# Story catalog: writing review & ratings

**Reviewer:** Composer (AI), May 2026.  
**Methodology:** Each synced tale in `assets/stories/<id>.md` was sampled (typically opening ~35–120 lines, plus mid/late passages on longer pieces). **Andrea and Lucas** was reviewed from the **full** Markdown export in `dist/andrea-and-lucas-complete/story.md` (~58k words as synced). Ratings are **subjective** on four axes, each **1–10** (higher = stronger).

| Axis | Meaning |
|------|--------|
| **Writing** | Prose clarity, voice, dialogue, pacing, structure, polish |
| **Ambition** | Scope, formal experimentation, ensemble/worldbuilding, thematic reach |
| **Immersion** | Believable stakes, scene continuity, “stay-in-story” pull |
| **Eroticism** | Heat, specificity, payoff, niche delivery for the catalog’s core kink |

**Caveats:** Stories **41** (Road Trip), **47** (Andrea Part 2), and **48** (Quality Control) had no local `assets/stories/*.md` at sync time — entries are marked **N/A (not synced)**. **Id 3** does not exist in `data/stories.js`. Short pieces are penalized slightly on **Ambition** by design. This file is a snapshot; prose may change when Drive docs update.
